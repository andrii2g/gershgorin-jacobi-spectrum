SVG coordinate attributes are finite. Diagnostics validate the exported eigenvalues after final rescaling, not only the internal diagonal. A deliberately subnormal case confirms that unavoidable eigenvalue quantization is visible in residuals. Containment alone also demonstrably fails to validate a deliberately inaccurate, loosely converged result.

## Benchmark evidence and remaining limits

The small comparison measured both policies for all five families at n=4,8,16: one warmup and two timed repetitions per policy, with alternating execution order. Raw timing samples, status/counters, medians, minima and maxima are in `artifacts/verification-compare/comparison.json` and `.csv`. Timed solves have trace/snapshots disabled and include cloning/V allocation. Original residual validation happens after stopping the timer. Gershgorin timing batches include interval merging; each batch targets 20 ms or a 100000-call cap. Timings are machine/load dependent and are not asserted in CI.

Not executed:

- Docker verification/runtime image builds: no Docker executable is installed on this host.
- Remote GitHub Actions: workflow is present, but no push or remote run was requested for this verification.
- Linux/ARM execution and cross-architecture comparisons; the Bash CI script is configured but not executed on this Windows host.
- Large n>64 performance studies, exhaustive adversarial floating-point testing, or certified eigenvalue computation.

The known limits remain dense-memory/search cost, lost tiny entries under extreme scaling, and representability/relative-accuracy limits for tiny eigenvalues. Outward scalar interval arithmetic is distinct from certification of computed eigenpairs. No external eigensolver library or unexecuted performance measurement is presented as validation.
